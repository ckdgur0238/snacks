# Snack Voyage 쇼핑몰 데모

## 실행
`index.html`을 브라우저에서 열면 됩니다. 인터넷 연결 없이 로컬 이미지와 프론트엔드 기능을 확인할 수 있습니다.

## 구성
- `index.html`: HTML, CSS, JavaScript가 모두 포함된 단일 페이지
- `img/`: 히어로 슬라이드 및 상품/프로모션 이미지

## 데모 기능
- 4장 히어로 자동 슬라이드
- 상품 검색 및 장바구니 담기/수량 변경
- 브라우저 localStorage 기반 회원가입/로그인
- 신규 가입 1,000P, 회원 등급별 구매 적립률
- 주문서 및 포인트 사용을 포함한 결제 흐름 시뮬레이션

## 실제 서비스 전환 시 필요한 작업
현재 버전은 프론트엔드 프로토타입입니다. 실제 서비스에는 서버 기반 인증/회원 DB, 주문·재고 DB, 개인정보 보호 및 보안 처리, PG사(예: 토스페이먼츠/PortOne) 결제 승인·웹훅 연동, 배송·환불 정책과 관리자 페이지가 필요합니다.
브라우저 localStorage는 테스트용이며 실제 비밀번호나 개인정보를 저장하는 용도로 사용하면 안 됩니다.
